How Routing Works

Request flow through this platform

A client sends one request to POST /route. The engine filters vendors by capability and health, applies the selected routing strategy (priority, weighted, lowest cost, lowest latency, or failover), and calls the chosen vendor. If that vendor fails, the platform automatically retries the next best vendor before returning a response — the client never sees the underlying complexity.
